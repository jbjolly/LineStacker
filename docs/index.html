LineStacker¶

LineStacker stacks the spectral lines of many faint sources to measure their average emission: the line of each source is centred on its own redshift, then all sources are averaged channel by channel. It stacks

  • data cubes, FITS files or CASA images, around each source (LineStacker.image), for lines or continuum;

  • 1D spectra already extracted (LineStacker.OneD_Stacker);

and comes with tools to test what a stack shows: bootstrapping, subsampling to find the sources that dominate it, stacks at random positions, noise estimates, and rebinning or regridding of lines of different widths and redshifts.

import LineStacker
import LineStacker.image

# one row per source: ra, dec, z and the cube it lies in
coords = LineStacker.readCatalog('sources.csv')
fEm = 1897420620253.1646          # rest frequency of the line (Hz)
result = LineStacker.image.stack(coords, fEm=fEm, stampsize=16, N_chans=31)
# LineStacker: mean line stack of 30 sources (16x16 pixels, 31 channels)
#              written to .../stackResult.fits
spectrum = result[1]          # stacked spectrum of the central pixel

LineStacker 2.0 runs on Python 3 and CASA 6 (CASA is only needed for CASA images: FITS cubes need no CASA). See what changed in 2.0 if you used LineStacker 1.x.
